# Neural Mass Models and State Estimation

## Overview

This repository contains MATLAB and Simulink implementations of neural mass models used to simulate cortical EEG activity and investigate brain dynamics. It also includes state and parameter estimation techniques based on Kalman filtering.

---

## Implemented Models

### Jansen-Rit Neural Mass Model

- MATLAB implementation
- Simulink implementation
- EEG simulation
- Parameter tuning

---

### Wendling Neural Mass Model

- MATLAB implementation
- Simulink implementation
- Excitatory and inhibitory population dynamics
- Epileptic EEG simulation
